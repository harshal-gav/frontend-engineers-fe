# FrontendEngineers.com 🚀

Welcome to **FrontendEngineers.com**, the ultimate job board for 100% remote frontend developer roles. We aggregate jobs from 100+ boards, career pages, and platforms like LinkedIn to give engineers a single place to find top-tier React, Vue, Angular, and Next.js jobs.

## Features
- **Global Aggregation Engine:** Automated scrapers (Playwright) fetching remote frontend jobs worldwide.
- **AI-Powered Social Media:** Scheduled, engaging posts via Gemini AI.
- **For Developers:** Clean UI, fast search, direct apply links, and daily alerts (Pro tier at $9/mo).
- **For Employers:** Post unlimited jobs directly to 100K+ targeted frontend devs ($99/mo).

## Tech Stack
- **Frontend:** Next.js (App Router), Tailwind CSS
- **Backend:** Firebase Auth & Firestore
- **Payments:** PayPal & PayU Subscriptions
- **Automation:** Node.js, Playwright, Gemini API

## Setup
```bash
npm run dev
```
Set up `.env` with Firebase, PayPal, PayU, and Gemini API keys to run fully locally.
